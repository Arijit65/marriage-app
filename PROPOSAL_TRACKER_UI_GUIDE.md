## Status Colors Legend

- 🟡 **Pending** - Yellow badge - Waiting for response
- 🟢 **Accepted** - Green badge - Proposal accepted successfully
- 🔴 **Rejected** - Red badge - Proposal was declined
- ⚪ **Withdrawn** - Gray badge - Proposal withdrawn by sender

## Key Features Visible in UI

1. **Photo Display**: Profile photos with fallback for missing images
2. **Status Badges**: Color-coded for quick identification
3. **User Info**: Age, gender, occupation, location
4. **Message Preview**: First few lines of proposal message
5. **Action Buttons**: Context-aware based on proposal status
6. **Timestamp**: When proposal was sent/responded
7. **Search & Filter**: Easy to find specific proposals
8. **Pagination**: Navigate through many proposals

## Interaction Flow

1. **Click Sidebar** → "My Proposals Tracker" → Opens Tracker
2. **Switch Tab** → Toggle between Sent/Received
3. **Filter** → Select status from dropdown
4. **Search** → Type name/location to filter
5. **View Details** → Click to open modal with full info
6. **Accept/Reject** → Quick action or from detail modal
7. **Withdraw** → Remove pending sent proposals
8. **Paginate** → Navigate through multiple pages
